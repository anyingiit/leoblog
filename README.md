# LeoBlog

Small, reviewed releases for a static blog trial.

- Current trial: https://leoblog-prod.pages.dev/
- Versions and implementation progress are recorded in pull requests.
- This repository initially contains the reviewed static-site source subset.

## Verify locally

With Docker available, run `bash prod/static-site/scripts/test-minimal-pinned.sh`. It uses the pinned Node image and locked dependencies. See `prod/static-site/README.md` for artifact input requirements.
